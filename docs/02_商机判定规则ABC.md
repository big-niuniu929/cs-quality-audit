# 品牌A 客服质检系统 4.0 — A/B/C 商机判定规则（固化版 v1.0）

> 本规则融合：问卷答案、《思路.docx》、旧规则引擎 `rules/engine.py`、历史质检结果、话术文档。
> 目标：让规则引擎和 AI 用同一套标准，判定可解释、可复核、无歧义。

## 一、前置：先分流，再分级

商机分级只针对 **售前** 会话。售后不参与 A/B/C。

判断顺序固定为：

1. 先判 **售前 / 售后**（关键词 + 场景，语义不确定时进入人工复核）
2. **售后** → 只记「有效/无效」（看客服是否投入时间并解决问题），不分级
3. **售前** → 先判「有效/无效」，**有效才分级**

## 二、联系方式 = 单独标记（电销线索）

只要出现电话号码（正则 `1[3-9]\d{9}`）或客户主动留微信/联系方式：

- 单独标记 `tele_sales_lead = true`（电销线索，供运营跟进）
- 同时必为「有效」+「A 级」
- 不混入普通商机分类

## 三、A/B/C 判定规则

### A 级（强购买信号，立即跟进）—— 命中任一：

1. 留下联系方式（电话/微信/手机号）→ 同时标电销线索
2. 明确表达购买我方产品：`就买这个 / 下单 / 买一台 / 要了 / 确定买 / 多少钱能拿下`
3. 主动询问优惠/折扣/活动：`有优惠吗 / 双十一什么价 / 能便宜点 / 有活动吗`
4. 明确需求 + 明确购买时间：`过几天买 / 下周买 / 和家人商量完就下单`
5. 已锁定我方品牌，只在我方不同型号/套组间犹豫：`65 还是 75 好 / 要不要带架子`

### B 级（有购买意向，需主动跟进）—— 命中任一：

1. 竞品/其他品牌对比：`和华为比 / 和 XX 牌子哪个好 / 别的牌子呢`
2. 计划购买 / 复购：`打算买 / 下个月买 / 再买一台 / 还会买 / 以后会买`
3. 客户提了实质需求，但客服还没回答客户就离开

### C 级（培育线索，持续观察）—— 命中任一：

1. 多次咨询参数（客户消息 ≥ 2 条，围绕产品参数/功能）
2. 对话轮次较多，或跨天/隔天再次咨询
3. 有大概需求但无明确购买信号（AI 判断「有购买可能」）

### 无效（不参与分级）：

- 客户点链接进来，一句话没问就走（客服时间成本被浪费）
- 短会话（≤ 5 条消息）且无询价/购买/对比/优惠/联系方式信号
- 客服正常回答后客户离开，且无任何购买信号
- **内部人员闲聊** → 标「无效 + 特殊原因（内部闲聊）」，需 AI 辅助识别

## 四、关键区分（消除「犹豫对比」的歧义）

「对比」分两种，不混：

| 场景 | 等级 |
|---|---|
| 对比 **竞品/其他品牌**（华为、小米、别的牌子） | **B** |
| 已锁定我方、只在我方**不同型号/套组间**犹豫 | **A** |

## 五、与历史「重点关注 √/√√」的映射

历史用 √√ / √ 标记，新版映射到 A/B/C：

| 历史标记 | 含义 | 新版映射 |
|---|---|---|
| √√ | 需求已谈透，建议优先回访 | ≈ A |
| √ | 有明确兴趣点但没挖透 | ≈ B |
| 无标记但有培育价值 | 多次咨询 / 跨天 | ≈ C |

## 六、优先级（命中多个取最高）

**A > B > C**。一条会话按命中的最高信号定级，但所有命中的原因码都要记录，便于复核和解释。

## 七、与评分的关系

- A/B/C 是**商机等级**，不是分数，不等同绩效结论。
- 评分是另一条线（100 分向下扣分），两者独立展示，都要给出原因。
