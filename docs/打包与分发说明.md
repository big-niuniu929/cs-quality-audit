# 打包与分发说明（内部）

## 一、Windows（已可直接分发）

产物目录：`dist\全量自动化客服质检系统\`

1. 双击 `build_windows.bat` 可重新构建（需本机已装 Python 3.10+ 与 requirements 依赖、pyinstaller）。
2. 构建完成后会自动把 `config`、`docs`、`README_给同事.md` 复制进去，并生成空的 `data` 目录。
3. 分发方式：把 `dist\全量自动化客服质检系统` **整个文件夹**压缩成 zip 发给同事，解压后双击 `全量自动化客服质检系统.exe` 即可，无需安装 Python。
4. 收件人首次运行若出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。程序未签名，属正常现象。

### 注意（安全）
- **不要**把开发机上带密钥的 `config\ai_config.json` 打进包里。构建脚本会删除它并用 `config\ai_config.example.json`（空密钥）代替。
- 同事在「智能设置」里自行填写接口密钥即可启用 AI；不填也能正常使用规则质检、复核与导出。

## 二、macOS

- 代码本身跨平台（PyQt6 / SQLite / openpyxl 均支持 macOS），但 **Windows 打出的 exe 不能给 Mac 用**。
- 在 Mac 上：安装 Python 3.10+ → `pip install -r requirements.txt pyinstaller` → 运行 `build_macos.command`，产物在 `dist/全量自动化客服质检系统.app`。
- Apple 芯片（arm64）与 Intel（x86_64）需要在对应机型上分别构建；若被系统拦截，执行：
  `xattr -dr com.apple.quarantine dist/全量自动化客服质检系统.app`
- Mac 版的数据与配置建议放在 `.app` 同级目录（脚本已按此处理），升级时保留该目录即可。

## 三、升级与数据

- 程序目录结构：`程序文件 + config\（规则、店铺、AI 配置） + data\qc.db（数据库）`。
- 升级：用新版本替换程序文件，**保留 config 与 data**，历史数据与店铺配置不会丢。
- 备份：直接复制 `data\qc.db` 即可。

## 四、常见问题

- 双击没反应：先用命令行运行 exe 看报错（exe 是控制台程序，报错会显示在窗口里）。
- 首次启动慢：解压/首次载入字体与初始化数据库，属正常。
- 公司杀毒软件拦截：未签名的内部工具可能被拦，加入信任即可。
