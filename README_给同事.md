# 全量自动化客服质检系统 使用说明（爆单一铲）

1. 解压压缩包，双击 `全量自动化客服质检系统.exe`，无需安装。
2. 首次使用：
   - 「数据导入」：选择聊天记录 `.log` 与会话记录 `.xlsx`，选择店铺，点「开始质检导入」。
   - 「智能设置」：如需 AI 质检，填写接口地址、模型与密钥并保存（不填不影响规则质检）。
3. 日常使用：总览筛选查看 → 双击行看聊天与扣分明细 → 人工复核改分 → 电销跟进回访 → 导出 Excel。
4. 数据位置：程序旁边的 `data\qc.db`；升级程序时保留 `config` 与 `data` 文件夹。
5. 完整操作手册见 `docs\全量自动化客服质检系统_使用说明书.html`（用浏览器打开）。

遇到问题请把报错截图（含终端窗口内容）发给技术支持。


## 新增：爆单一铲（AI 质检副驾）

在「质检总览」右上角点 **爆单一铲** 按钮，会弹出 AI 对话窗口：

1. **数据范围**：窗口右上角可切「当前筛选 / 全部数据」，默认使用总览当前筛选。
2. **提问方式**：点上方胶囊快速填入专业提问（质保/会议室场景/竞品对比/商机信号/话术改写），或直接输入问题。
3. **数字类问题**（多少条、占比、排名）会走全量 SQL 精确统计，可在聊天里看到执行的只读 SQL；
   内容类问题（共性、话术、质保等）超过 200 条时会让你选：全量分批分析（覆盖全部，较慢）或快速分析（前 200 条）。
4. 回答可以中途「停止」，历史对话自动保存，左侧列表可回看。
5. AI 需要先在「智能设置」填接口密钥；不填不影响规则质检、复核、导出。

## 运行平台（都不需要安装 Python）

- **Windows**：解压后双击 全量自动化客服质检系统.exe 即可（已内置运行环境）。
- **macOS**：解压后双击 全量自动化客服质检系统.app 即可；构建方法见 docs/macOS_使用说明.md。
- 数据、配置都在程序旁边：data/（会话库+聊天历史）、config/（接口与规则）；整个文件夹一起备份/迁移。

## v5.0 更新：双看板 + 新评分规则

- **角色看板**：质检总览右上角可切换「运营 / 客服」。运营看板保持原样；客服看板每条咨询直接展示 6 个维度得分百分比，支持「放大列表/缩回」全屏查看，双击仍可看聊天记录。
- **评分规则库**：废弃旧版/新版切换，统一为一套三层档位规则（每维扣 33%/63%/100%，即得 67%/37%/0%）；话术匹配、问题解决由 AI 质检，未完成时显示「待AI质检」。
- 两套看板共用同一数据与评分，分数一致；跑完「全量智能质检」后自动重算 AI 维度。

### v5.1 补充

- **看板筛选共用**：运营/客服两套看板顶部是同一套搜索与筛选，切换角色不会丢条件；
- **客服看板**：新增“按客服汇总大表”（咨询数、平均分、合格率、待AI、待复核、平均扣分、有扣分比例、6 维度得分率），点击某客服行即可筛选下方明细，点「全部客服」或「清除筛选」恢复；保留放大列表；
- **运营看板**：新增「放大列表 / 缩回」；
- **详细评分标准**：点「评分规则」可看每个维度 67%/37%/0% 三档的具体达标条件；
- **导入批次可编辑**：数据导入页双击批次行（或点「编辑选中批次」）可修改店铺标记和备注，店铺修改会同步该批次全部会话。

- **导入中断修复**：导入失败/中断不再留下“有批次、没数据”的空壳；启动自动清理空批次；数据导入页有「修复空白批次」按钮；重新导入同一文件可直接恢复。

### v5.2 评分与看板升级

- **评分规则换成 100 分四档制**：响应速度 10、售前必问 25、话术匹配 10、问题解决 30、引导留资 20、优惠触达 5；每维按优秀/良好/合格/不合格给分，话术/问题解决由 AI 判断，AI 未完成显示「待AI质检」。
- **客服看板**分「客服汇总 & 统计」「咨询明细」两个子页：新增客服平均分对比、6 维平均得分率柱状图；保留完整筛选、AI 质检、爆单一铲、导出等基础功能。
- **维度得分条**：明细每条咨询的 6 个维度用单元格数据条展示得分率（100% 填满）。
- **隐藏列**：运营/客服明细表都有「列」按钮，可像 Excel 一样显示/隐藏任意列。
- **一键复核**：人工复核页可批量确认当前判断，待AI/售后记录会跳过。
- **建议列**：原“跟进建议”改为“建议”，优先展示 AI 语义生成的改进建议（服务/话术/产品推荐），没有 AI 时展示规则建议。
- **删除运营看板“按新标准重算评分”按钮**：单一规则库下导入和 AI 完成会自动重算，无需手动。
